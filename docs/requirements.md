# Requisitos del proyecto

## Hechos confirmados

### Objetivo

Desarrollar desde cero un aplicativo para gestionar mejor la flota de vehículos de Petrocasinos.

### Estado

El proyecto se encuentra en la etapa de definición de requisitos.

### Relación con la versión anterior

Existe una versión anterior, pero este proyecto será un desarrollo nuevo. No se buscará, importará ni reutilizará su código, archivos, base de datos o arquitectura.

## Propuestas

No hay propuestas aprobadas o en evaluación registradas hasta el momento.

## Asuntos pendientes

- Identificar los problemas actuales y las lecciones de la versión anterior, sin acceder ni reutilizar sus activos.
- Definir los usuarios y sus permisos.
- Definir los procesos prioritarios.
- Delimitar el alcance y las exclusiones de la primera entrega.
- Documentar las reglas de negocio y los criterios de aceptación.
- Definir el entorno de ejecución y el modelo de mantenimiento.
- Tomar y documentar las decisiones técnicas pendientes, incluidas las tecnologías y el entorno de despliegue.

Ninguno de estos asuntos debe considerarse definido o aprobado hasta que se tome y documente la decisión correspondiente.
