# Aplicativo de gestión de vehículos de Petrocasinos

## Objetivo general

Desarrollar un aplicativo que permita gestionar mejor la flota de vehículos de Petrocasinos.

## Estado del proyecto

El proyecto se encuentra en la etapa de definición de requisitos. Las funcionalidades, las tecnologías y el entorno de despliegue todavía no han sido definidos ni aprobados.

Este será un desarrollo nuevo. No se buscará, importará ni reutilizará código, archivos, bases de datos o arquitectura de la versión anterior.

Los hechos confirmados y los asuntos que requieren definición están registrados en [docs/requirements.md](docs/requirements.md).
